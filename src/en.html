06 · Trust

How reliable is this AI?

An officer who talks about someone must remain honest, respect privacy and not be misled. That is not promised here, but measured: with its own evaluation set and an automated attack scan of the AI Red Teaming Agent in Microsoft Foundry.

  • Content filters and Prompt Shields from Foundry block malicious queries and jailbreaks before the agent.
  • Instructions with hard limits: no personal data, no speculation, no customer names.
  • Keyless: no API keys; only managed identities with minimal permissions.
  • Cost brakes: Native token limit per feature, maximum calls, and duration.
  • Tracing: Every conversation can be seen in Application Insights.
